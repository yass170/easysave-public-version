# Architecture générale — EasySave

Projet de gestion de sauvegardes, présenté sous la forme d’une arborescence anonymisée.

La structure distingue l’application, les modèles, les services, les interfaces et les tests. Les composants de sauvegarde et de journalisation sont représentés par leurs dossiers. Les échanges entre composants et les règles de sauvegarde ne sont pas publiés.

Formats techniques représentés dans la copie : C# / .NET, XAML, configuration textuelle.

Cette présentation a été rédigée pour la version publique à partir des catégories de fichiers et de dossiers. Elle ne reproduit aucun document interne et ne décrit pas une application exécutable. Les noms spécifiques ont été remplacés par des noms génériques.
